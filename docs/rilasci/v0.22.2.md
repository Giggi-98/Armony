## Armony 0.22.2

Cambiare versione a un brano mentre lo ascolti ora è indolore, e l'app non resta più appesa quando il server non risponde.

- **Cambio versione dai Dettagli**: dopo «Scegli un'altra versione» una barra mostra l'avanzamento; a sostituzione finita durata e dati del brano si aggiornano da soli.
- **Il brano che stai ascoltando si ferma e riparte da solo**: se sostituisci proprio quello in riproduzione, si ferma subito (il file sta per cambiare) e riparte da capo con la versione nuova appena è pronta. Vale sul web e nell'app Android. Se la sostituzione non riesce, riprende da dove era.
- Dopo una sostituzione non si sente più il file vecchio dalla cache dei brani.

### Correzioni
- **Pagine che restavano in caricamento per sempre** quando la connessione con il server si interrompeva a metà (tunnel instabile, riavvio del server): ora ogni chiamata ha un tempo massimo, le letture si riprovano una volta e, se il server non risponde, compare «non risponde» con Riprova.
- Le impostazioni dei server collegati non danno più errore se si cambia pagina mentre si caricano.
