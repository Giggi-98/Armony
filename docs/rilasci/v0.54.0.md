## Armony 0.54.0

- **Trasferire il server su un altro computer**: Impostazioni → Trasferimento. Sul nuovo «Ricevi un server», sul vecchio «Trasferisci questo server»: confrontate il codice di sicurezza e il nuovo prende tutto, utenti e password, playlist, preferiti, ascolti, dispositivi (si spostano da soli) e la stessa identità per i server collegati. I brani a scelta: senza, il vecchio resta come libreria collegata e li sposti dopo.
- **Federazione, pagina sua**: si apre dal gruppo Rete a tutta larghezza, non più fra le impostazioni; sul telefono da Rete → «Gestisci la federazione».
- **Server che cambiano indirizzo**: i server collegati seguono da soli un server spostato, dopo aver controllato che al nuovo indirizzo risponda lo stesso server.
- Il nuovo server deve avere il servizio del tasto «Aggiorna» attivo (lo installa `installa.sh`): è lui che applica i dati ricevuti.
