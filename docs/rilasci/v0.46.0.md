## Armony 0.46.0

- **Radio da internet**: nella sezione Radio, «Aggiungi una radio» cerca fra decine di migliaia di stazioni o accetta l'indirizzo dello stream. Le radio aggiunte restano pronte per tutti: un tocco e partono, con «Diretta» nel lettore. Funzionano anche le radio in http e l'equalizzatore, perché l'audio passa dal server.
