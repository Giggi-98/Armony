## Armony 0.50.0

- **Server senza indirizzo pubblico collegati agli altri**: un server senza IP pubblico statico, dietro un firewall o su un PC con WSL si aggancia a un server raggiungibile come un client: lascia vuoto «Indirizzo per gli altri server», incolla l'invito del server raggiungibile e, quando l'altro accetta, la sua libreria compare da lui entro un minuto. Serve la 0.50 su tutti e due.
- **Niente più «indirizzo interno di questo server»**: aprendo Armony da 127.0.0.1, incollare un invito non si blocca più su quell'indirizzo.
- **Catalogo subito**: quando un server dietro NAT apre il suo canale, chi lo ospita scarica subito la sua libreria invece di aspettare il giro dopo (anche 20 minuti).
- Librerie collegate: una riga spiega quando lasciare vuoto l'indirizzo, e un server senza indirizzo compare come «senza indirizzo: passa dal suo canale».
