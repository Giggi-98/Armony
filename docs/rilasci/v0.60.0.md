## Armony 0.60.0

- **Trasferimento nella rete di casa senza codice**: su «Trasferisci questo server» compaiono i server Armony trovati nella rete; tocchi quello nuovo (deve avere «Ricevi un server» aperto) e si collega.
- **Oppure scrivi l'indirizzo** del server nuovo (per esempio `192.168.1.50:8080`, lo mostra lui in «Ricevi un server»); il codice ART1 resta per le reti diverse.
- **La copia passa dalla rete di casa**: più veloce e senza dipendere dal router; agli altri server si annuncia comunque l'indirizzo pubblico del nuovo.
- Il codice di sicurezza va sempre confermato sul nuovo prima dell'avvio, e senza codice si accettano solo richieste dalla rete di casa.
