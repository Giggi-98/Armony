## Armony 0.60.1

- **L'indirizzo pubblico non si sporca più**: con `ARMONY_DOMAIN` nel `.env` è sempre `https://` + quel nome, per dispositivi, link, inviti e server collegati, anche dopo un trasferimento.
- **Il trasferimento si ferma se il nuovo server si presenterebbe con un indirizzo di casa** (per esempio `http://192.168.…`) mentre il vecchio si usa da internet, e dice cosa fare.
- **Quando l'indirizzo cambia, i server collegati lo sanno da soli.**
- **Più sicurezza sulla pagina**: niente Armony dentro le pagine di altri siti, HTTPS obbligatorio per il browser (HSTS), il software del server non si dichiara più.
- Dopo un server reinstallato o trasferito la pagina non resta più «in attesa di approvazione» per sempre: chiede di accedere di nuovo, senza far scattare il blocco per troppi tentativi.

### Correzioni
- Il collaudo automatico non dice più «tutto a posto» quando i server di prova non si installano.
