## Armony 0.57.0

- **Brani di fila senza buchi (gapless)**: senza dissolvenza, e sempre fra brani consecutivi dello stesso album, il brano dopo parte una frazione di secondo prima della fine del precedente. Album dal vivo e concept suonano legati.
- **Due dispositivi che partono insieme**: se due tuoi dispositivi cominciano a suonare quasi nello stesso istante, continua quello partito prima invece di fermarsi a vicenda.
- **«Dove suona» anche sul server di un amico**: passando nell'app al server di un amico per ascoltarlo, resti visibile e comandabile dal tuo server di casa.
- **Testi**: il giro che cerca i testi sul server non si ferma più per un'ora al primo errore di LRCLIB, ma riprova.
