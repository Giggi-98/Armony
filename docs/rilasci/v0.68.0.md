## Armony 0.68.0

### ✨ Novità
- 🔑 **Chiavi API per il tuo homelab**: in Impostazioni → Chiavi API crei una chiave per una plancia, Node-RED o uno script di casa. Vede in tempo reale cosa suona, chi ascolta, download e brani nuovi, e se vuoi comanda la musica.
- 👀 **Guarda senza disturbare**: il programma collegato con una chiave riceve la diretta ma non compare fra i tuoi dispositivi in «Dove suona».
- 🔒 **Sicure di base**: valgono solo da casa o da Tailscale, possono essere di sola lettura, non creano altri accessi e si revocano con un tasto (il programma viene staccato subito).
